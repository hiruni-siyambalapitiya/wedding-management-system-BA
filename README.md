# wedding-management-system-BA
Business Analyst project for a Wedding Management System including requirement analysis, UML diagrams, and Power BI dashboard insights.

Project Overview
 
 The Wedding Management System is designed to simplify and streamline wedding planning activities. It helps clients efficiently book vendors, manage budgets, and track event progress while reducing manual coordination and communication gaps.

🎯 Objectives

Simplify vendor booking process
Reduce manual coordination
Avoid vendor scheduling conflicts
Enable real-time budget tracking
Improve communication between stakeholders

👥 Stakeholders

Clients (Couples)
Vendors (Photographers, Caterers, Decorators)
Admin
Wedding Planners

⚙️ Key Features

User Registration & Login
Wedding Plan Creation
Vendor Browsing & Booking
Vendor Availability Management
Booking Approval Workflow
Budget Tracking
Notifications

Business Analysis Artifacts

📌 BRD (Business Requirement Document)

Defines business goals, scope, and high-level requirements.

📌 FRD (Functional Requirement Document)

Describes system functionalities and workflows in detail.

📌 User Stories & Acceptance Criteria

Created for:

Client (Booking vendors)
Vendor (Managing availability)
Admin (Approving bookings)

UML Diagrams
Use Case Diagram
Activity Diagram

Power BI Dashboard

A dashboard was created to analyze:

Total bookings
Booking status (Approved / Pending / Rejected)
Budget vs Cost
Vendor performance
City-wise booking distribution
